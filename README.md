## Projeto principal · Solara PDV

Sistema de gestão para ponto de venda que reúne **produtos, clientes, vendas, caixa e catálogo**, além da administração de licenças e dispositivos. O backend expõe uma **API REST em Laravel** com autenticação via **Sanctum**, e a interface usa **React, TypeScript, Vite e Tailwind CSS**.
