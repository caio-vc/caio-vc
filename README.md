# Caio Vinícius

**Ciência da Computação · Desenvolvimento web · Automação e suporte de TI**

Desenvolvo ferramentas para simplificar tarefas do dia a dia. Na hotelaria, transformei uma conferência manual de reservas em uma extensão de navegador. Como analista de TI, trabalhei com desenvolvimento de sistema de gestão, implantação de PDV, suporte técnico e treinamento de usuários.

## Projetos em destaque

| Projeto | O que faz | Tecnologia |

| [Contador de reservas para Green Software](https://github.com/caio-vc/green-software-marulhos-extension) | Separa reservas de hotel e condomínio, conta unidades e apresenta indicadores de ocupação em um painel. | JavaScript, HTML e CSS |
| [Baixador de mídia do Mercado Livre](https://github.com/caio-vc/baixador-midia-mercado-livre) | Extensão de navegador para identificar e baixar fotos e vídeos de anúncios. | JavaScript, extensão de navegador |

- **Automação:** extensões de navegador em JavaScript e bots em Python.
- **Operações de TI:** implantação de sistemas, configuração de ambientes, suporte técnico e treinamento de usuários.
- **Versionamento:** Git e GitHub.
